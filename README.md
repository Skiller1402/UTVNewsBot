# UTV News Bot

Telegram-бот для бронирования съемочной техники. Бот позволяет выбрать оборудование, указать название съемки, дату или период бронирования, время начала и окончания, а также посмотреть и удалить свои брони.

## Возможности

- Бронирование одной или нескольких позиций техники.
- Название съемки для каждой брони.
- Однодневные брони с выбором времени.
- Многодневные брони на полный день `09:00-22:00`.
- Проверка конфликтов по дате, времени и совпадающей технике.
- Просмотр своих броней.
- Просмотр всех броней по дате.
- Удаление только своих броней.
- Поддержка SOCKS proxy для Telegram API.
- Graceful shutdown при остановке процесса.

## Установка

```bash
npm install
```

## Настройка `.env`

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=your_telegram_bot_token
```

Если Telegram API доступен только через SOCKS proxy, добавьте:

```env
TELEGRAM_SOCKS_PROXY_URL=socks5h://USER:PASSWORD@HOST:PORT
```

Рекомендуется использовать `socks5h://`, чтобы DNS-запросы тоже шли через прокси.

Также поддерживаются переменные:

```env
SOCKS_PROXY_URL=socks5h://USER:PASSWORD@HOST:PORT
ALL_PROXY=socks5h://USER:PASSWORD@HOST:PORT
```

Приоритет: `TELEGRAM_SOCKS_PROXY_URL`, затем `SOCKS_PROXY_URL`, затем `ALL_PROXY`.

## Запуск локально

```bash
npm start
```

Для разработки:

```bash
npm run dev
```

Важно: один Telegram bot token может быть запущен только в одном polling-процессе. Если бот уже работает на сервере, локальный запуск с тем же `BOT_TOKEN` вызовет ошибку `409 Conflict`.

## Запуск на сервере через PM2

Рекомендуемый вариант для продакшена:

```bash
npm install
npm install -g pm2
pm2 start index.js --name UtvNews_BOT
pm2 save
pm2 startup
```

После `pm2 startup` выполните команду, которую покажет PM2.

Полезные команды:

```bash
pm2 list
pm2 logs UtvNews_BOT
pm2 restart UtvNews_BOT
pm2 stop UtvNews_BOT
```

После обновления кода:

```bash
git pull
npm install
pm2 restart UtvNews_BOT
```

## Сценарий бронирования

1. Пользователь нажимает `Забронировать оборудование`.
2. Выбирает одну или несколько позиций техники.
3. Нажимает `Далее`.
4. Вводит название съемки или нажимает `Пропустить`.
5. Выбирает дату начала.
6. Выбирает один день или период.
7. Для одного дня выбирает время начала и окончания.
8. Бот проверяет конфликты и сохраняет бронь.

## Хранение данных

Брони хранятся в `bookings.json`.

Запись выполняется через временный файл и замену основного файла, чтобы снизить риск повреждения данных при сбое. Проверка конфликта и сохранение выполняются под локом внутри процесса.

Если бот будет запущен в нескольких процессах одновременно, JSON-хранилище не защитит от межпроцессных гонок. Для такой нагрузки лучше перейти на SQLite.

## Частые ошибки

### `409 Conflict: terminated by other getUpdates request`

Запущено несколько экземпляров бота с одним `BOT_TOKEN`.

Оставьте только один процесс:

```bash
pm2 list
pm2 stop UtvNews_BOT
pm2 delete UtvNews_BOT
pm2 start index.js --name UtvNews_BOT
```

### `RequestError: AggregateError`

Обычно это сетевой сбой до Telegram API. Проверьте доступность сети, настройки SOCKS proxy и значение `TELEGRAM_SOCKS_PROXY_URL`.

### Ошибка про `socks-proxy-agent` и dynamic import

Проект CommonJS, а `socks-proxy-agent` загружается через динамический `import()`. Если ошибка все еще появляется на сервере, убедитесь, что там обновлен `index.js` и выполнен `pm2 restart`.

## Структура проекта

- `index.js` - основной Telegram-бот и обработчики сценариев.
- `bookingService.js` - логика броней, конфликтов и удаления.
- `storage.js` - чтение и запись `bookings.json`.
- `timeUtils.js` - утилиты времени.
- `createBooking.js` - создание файла броней при первом запуске.
- `tests/` - тесты Jest.
